# Repository governance templates

Copy these files into new or existing repositories and adjust placeholders marked `TODO` or `{{...}}`.

| Template | Target path in your repo |
|----------|--------------------------|
| [README.template.md](./README.template.md) | `README.md` |
| [CONTRIBUTING.template.md](./CONTRIBUTING.template.md) | `CONTRIBUTING.md` |
| [CODEOWNERS.template](./CODEOWNERS.template) | `CODEOWNERS` or `.github/CODEOWNERS` |
| [pull_request_template.md](./pull_request_template.md) | `.github/pull_request_template.md` or `.github/PULL_REQUEST_TEMPLATE.md` |
| [issue_template_bug.md](./issue_template_bug.md) | `.github/ISSUE_TEMPLATE/bug_report.yml` (adapt to YAML form) or use as markdown body |
| [issue_template_feature.md](./issue_template_feature.md) | `.github/ISSUE_TEMPLATE/feature_request.yml` |
| [adr-template.md](./adr-template.md) | `docs/adr/NNNN-title.md` |
| [service-metadata.yaml](./service-metadata.yaml) | `service.yaml` (or `catalog/service.yaml`) |
| [docs-index.template.md](./docs-index.template.md) | `docs/README.md` |
| [runbook-template.md](./runbook-template.md) | `docs/runbooks/<service>-operations.md` |
| [SECURITY.template.md](./SECURITY.template.md) | `SECURITY.md` |
| [rep-pilot-nomination.template.md](./rep-pilot-nomination.template.md) | issue for pilot candidate intake (`.github/ISSUE_TEMPLATE/`) |
| [rep-weekly-status.template.md](./rep-weekly-status.template.md) | weekly status update note for EMs/owners |

**GitHub Issue Forms (native UI):** copy from this repo’s `.github/ISSUE_TEMPLATE/rep-pilot-nomination.yml` and `rep-weekly-status.yml` (or open issues here and use the templates).
