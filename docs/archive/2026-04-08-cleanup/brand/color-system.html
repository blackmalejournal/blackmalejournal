5. Image Treatment Reference

src/styles/globals.css — three treatment variants via TreatedImage component

Halftone (editorial)
Standard editorial images. Article covers, card images. Partial desaturation with contrast boost.
/* .halftone — editorial variant */
.halftone {
  filter: contrast(1.2) grayscale(0.3);
  mix-blend-mode: multiply;
}
Halftone Heavy (portrait)
Author portraits, profile images. Full newsprint treatment with dot overlay. Wrap in a .halftone-dots parent.
/* .halftone-heavy — portrait variant */
.halftone-heavy {
  filter: contrast(1.6) grayscale(1) brightness(1.1);
  mix-blend-mode: multiply;
}

/* .halftone-dots — dot overlay on parent */
.halftone-dots::after {
  content: "";
  position: absolute;
  inset: 0;
  background: radial-gradient(circle, #0D0C0B 1px, transparent 1px);
  background-size: 4px 4px;
  opacity: 0.3;
}
Duotone (hero)
Hero banners, full-width images. Complete grayscale with contrast, multiply-blended over brand background color.
/* .duotone — hero variant */
/* Parent must have a brand bg color */
.duotone {
  filter: grayscale(1) contrast(1.3);
  mix-blend-mode: multiply;
}
React Usage

6. Do / Don't

Brand invariants — prohibited patterns vs correct patterns

DO — Sharp corners
Sharp Card

border-radius: 2px or 4px max. Militant, deliberate.

rounded-sm (2px) or rounded (4px) only
DON'T — Rounded corners
Soft Card

rounded-md, rounded-lg, rounded-xl — all prohibited.

rounded-md and above are PROHIBITED
DO — Flat surfaces
Flat Element

Border for definition. No elevation. No depth illusion.

Use borders (1px solid) for visual separation
DON'T — Drop shadows
Shadowed Element

shadow-sm, shadow-md, shadow-lg — all prohibited.

shadow-* classes are PROHIBITED on brand components
DO — Solid color fills
SUBSCRIBE NOW
LEARN MORE
Flat, solid brand colors. Opacity for fades, never gradients.
DON'T — Gradients
SUBSCRIBE NOW
LEARN MORE
bg-gradient-* classes are PROHIBITED. No color transitions.
DO — Brand palette only
Only --bmj-* colors from brand.css. Dark, warm, militant.
DON'T — Pastels, blue, neon
Pastels, blue, neon, raw #FFF — all PROHIBITED.
DO — Grain texture overlay
Grain texture is applied globally via .grain::after. It adds grit and print authenticity.
Grain overlay at 0.09 opacity. Print-culture texture.
DON'T — Glassmorphism
Frosted glass effects, backdrop-blur, translucent panels — this is SaaS, not revolution.
backdrop-blur-* is PROHIBITED (except minimal nav scroll state)
DO — Hover increases weight
HOVERED STATE

Hover fills background, adds border, increases visual weight.

Hover should INCREASE visual weight or clarity
DON'T — Hover softens
HOVERED STATE

Opacity reduction, color lightening, fading text — prohibited.

Hover that reduces opacity or softens text is PROHIBITED
