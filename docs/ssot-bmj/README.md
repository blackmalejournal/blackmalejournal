# BMJ SSOT (synced from Downloads)

Markdown in this folder is copied from `Downloads/library/projects/bmj/` (all subfolders) by
`SSOT/scripts/sync-bmj-ssot-to-repo.ps1` (see `SSOT/scripts/run-all-maintenance.ps1`).

Edit either location, then re-run sync before committing if you changed the Downloads copy.
Canonical working copy for the Downloads SSOT layout: `library/projects/bmj/`.
