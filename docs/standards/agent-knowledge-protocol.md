# Contributor source ownership

[README](../../README.md) is the repository entry point and
[AGENTS](../../AGENTS.md) owns contributor instructions. Open the relevant
source, tests, and domain guide for the task. Runtime code owns values;
[environment](../ops/env-vars.md) and [brand invariants](../brand/invariants.md)
own their respective operating rules. Historical inputs and Git history supply
context and cannot override those sources or authorize new work.
