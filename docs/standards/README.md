# Standards — repository governance (reference)

This folder holds **Repo Excellence Program (REP)** reference material for multi-repo engineering organizations: baselines, templates, rollout, and metrics. It is **not** a substitute for BMJ product docs (`docs/DEVELOPER.md`, `docs/ARCHITECTURE.md`, etc.) unless leadership adopts specific items.

## Start here

| Document | Use when |
|----------|----------|
| [repo-governance-exec-readout.md](./repo-governance-exec-readout.md) | You need a **1–2 page VP/Platform briefing** (decision asks, guardrails). |
| [repo-governance-program.md](./repo-governance-program.md) | You need the **full program narrative** (executive summary through rollout, KPIs, naming). |

## Modules

| Document | Purpose |

| [migration-framework.md](./migration-framework.md) | Assessment, prioritization, checklist, **audit scorecard**. |
