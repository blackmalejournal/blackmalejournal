# Alawein Canonical Design System

Production-ready design system with 27 themes across 7 families. Implements a three-layer token architecture (primitives → semantic → theme-level) to minimize duplication across all themes.

## Quick Start

```bash
npm install
npm test
npm run build
```

## Architecture

- **Primitives** (300+ colors, typography, spacing, animations, shadows)
- **Semantic tokens** (status colors, interactive states, contrast levels)
- **Theme implementations** (7 families + hybrids + special editions)

## Distribution

- CSS custom properties
- JSON/Style Dictionary
- TypeScript validation
- Godot GDScript
- Web implementations
